## One proposed post for a professional audience

> A $90,000 open CRM pipeline is not a $90,000 revenue forecast.
>
> I made a small, fictional three-deal exercise for reviewing a sales forecast with AI. The prompt asks the model to add the amounts, flag missing buyer evidence, and suggest questions for each deal owner. It explicitly forbids made-up win probabilities and close confidence.
>
> The useful output is a review checklist: Which buyer action is confirmed? Which deal has gone quiet? Who can actually approve the purchase?
>
> Try the example and copy the prompt here: [tagged link]
>
> What evidence does your team require before moving a deal into commit?

## Measurement and decision

1. Record the publication date, account/channel, final copy, and exact tagged URL. Use one channel and one post initially; do not post from an account or contact anyone without the owner's direction.
2. For seven days, note any channel-reported outbound link clicks and substantive replies. If privacy-conscious aggregate site analytics becomes available, record tagged landing sessions and lesson-start events separately. Do not report impressions or reactions as website visits.
3. Seven-day **learning target**, not a benchmark: at least 10 attributable visits and one meaningful on-site action. If site analytics is unavailable, mark those two measures **unknown** rather than treating them as zero; use the channel's link-click count only if it is provided.
4. At the next weekly Search Console check, record the page's impressions and queries. Search Console Web data is delayed and does not attribute a social post, so do not use it to claim a seven-day traffic lift from this experiment.
5. Keep the page if readers find the exercise useful. Improve the lesson only when feedback or repeated search-query evidence identifies a specific gap. Do not repeat the same message across communities as a substitute for new value.
